# ANS Exam Downloader

Easily download your exam result PDFs directly from ans.app. This Chrome/Firefox extension allows you to download the original PDF document to your computer with a single click.

## Installation

### Chrome (Manual Installation)

To install this extension in Chrome manually, follow these steps:

1. **Download the Extension:**
   - Download the latest release `.zip` file here: [Download for Chrome](https://github.com/Piter13pp/Ans-Downloader/raw/main/Extension%20-%20chrome/Ans%20Exam%20Downloader.zip)

2. **Extract the Files:**
   - Unzip the downloaded file into a dedicated folder on your computer (e.g., `ans-downloader-extension`).

3. **Open Extensions in Chrome:**
   - Open Google Chrome.
   - Type `chrome://extensions/` in your address bar and press **Enter**.

4. **Enable Developer Mode:**
   - In the top-right corner of the Extensions page, toggle the **Developer mode** switch to the **ON** position.

5. **Load the Extension:**
   - Click the **Load unpacked** button that appears in the top-left menu.
   - Navigate to the folder where you extracted the ZIP file and select it.

6. **Pin the Extension (Optional but recommended):**
   - Click the "puzzle piece" icon in your Chrome toolbar.
   - Find "ANS Exam Downloader" and click the pin icon next to it for easy access!

## How to Use

1. Navigate to **ans.app** and log in to your account.
2. Open the exam you wish to download and ensure you are in the **"View Answers"** tab where the PDF is visible.
3. Click the **ANS Exam Downloader** icon in your browser toolbar.
4. Click the **Download PDF** button. The file will automatically save to your default downloads folder!
